# Задача по разработке и тестирования механизмов внешней аутентификации (OAuth2)

1. Пользователь (работа через браузер)
2. Клиент (наше основное приложение)
3. Сервис аутентификации + сервис предоставления ресурсов

## Разработка сервиса аутентификации + сервиса ресурсов

1. Регистрация приложения-клиента (id клиента, ключ, URL для редиректа) можно вручную
2. Реализация страницы для ввода логина/пароля, демонстрации необходимых
клиенту разрешений (email, id, ФИОб,...)
3. Реализация аутентификации, редирект на URL клиента + код для получения токена
4. Контроллер выдачи JWT токена по коду (идентификатор пользователя
на сервисе ресурсов, набор данных которые можно запросить по этому токену)
5. Контроллер выдачи ресурсов в обмен на токен

## Разработка приложения-клиента 

Предоставление аутентифицированному пользователю ресурсов приложения, аутентификация только
на внешнем сервисе

1. При не аутентифицированном запросе осуществлять редирект на сервис аутентификации + ключ клиента
2. Контроллер обработки кода получения токена (см. п. 3 выше), запросить JWT токен по коду,
на основании токена получить данные пользователя, подготовить контекст аутентифкации пользователя,
провести внутреннюю процедуру аутентификации, возврат пользователю ресурсов (index.html)
